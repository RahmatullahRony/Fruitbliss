# 🍎 Fruit Bliss

Fruit Bliss is an online e-commerce website for 100% organic fruits, developed by Md. Rahmatullah Rony, Mohammad Shakil & Mobinul Ahasan Tanjid. The platform allows users to browse a wide range of fresh fruits, view detailed product information, sign up or log in to their accounts, add products to the cart, and place secure orders. It also includes a smooth checkout process with order confirmation, a contact form for support, and a user-friendly interface to enhance the shopping experience.

## Features

- **Homepage (Before Login)**
  - Browse products and categories
  - View highlights and offers
  - Search functionality

- **Authentication**
  - Login (Phone/Email + Password)
  - Signup/Registration (Name, Email, Address, Gender, Date of Birth, Password)

- **After Login**
  - Personalized homepage with Log Out option
  - **User Profile Page**: View First Name, Last Name, Email, Gender, DOB, City, Address
  - **Shop Page**: Browse products with categories
  - **Shop Detail Page**: Product image, description, price, weight, origin, quality, related products, etc
  - **Shopping Cart Page**: View items, modify quantity, subtotal, shipping, total
  - **Checkout / Order Summary Page**: Final order overview and payment method
  - **Order Confirmation Page**: Success message, Transaction ID, Continue Shopping button

- **Contact Page**
  - Contact form (Name, Email, Message)
  - Display shop info: Address, Email, Phone
  - Payment accepted info

- **Other Features**
  - Free shipping on orders above BDT-700
  - Secure payment
  - 30-day return policy
  - 24/7 customer support

## Installation / Run Locally


1. Clone the repository:
   ```bash
   git clone https://github.com/RahmatullahRony/Fruitbliss

2. Move the project folder into your XAMPP htdocs directory:
        
        C:\xampp\htdocs\FruitBliss


3. Start XAMPP Control Panel and make sure:

Apache is running

MySQL is running

4. Open the project in your browser:

http://localhost/FruitBliss


5. Database Setup 

5.1 Open phpMyAdmin in your browser:

    http://localhost/phpmyadmin


5.2 Create a new database (e.g., fruitbliss).

5.3 Import the provided .sql file:

    Click on your database → Import

    Select the .sql file from the project folder

    Click Go

5.4 Update your database configuration in the project’s config file:

    $servername = "localhost";  
    $username   = "root";   
    $password   = "";      
    $dbname     = "fruitbliss";
